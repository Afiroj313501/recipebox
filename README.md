# Recipe Box AI

A smart kitchen assistant — store your recipes, tell it what's in your kitchen, and get AI-powered recipe suggestions.

## Stack
- **Client:** React 18 + Vite, TailwindCSS, shadcn/ui, Framer Motion
- **Server:** Node.js, Express, MongoDB (Mongoose)
- **AI:** Google Gemini (two-stage: DB match → Gemini fallback)

## Structure
- `/client` — React frontend
- `/server` — Express API
